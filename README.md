# Nova — Calculatrice scientifique

Calculatrice scientifique web en français, responsive, installable et utilisable hors ligne.

## Lancer le projet

```powershell
npm.cmd install
npm.cmd start
```

Puis ouvrir `http://127.0.0.1:4173`.

## Fonctions principales

- trigonométrie en degrés ou radians, logarithmes, puissances, racines, factorielle et constantes ;
- touche `2nd` pour les fonctions inverses ;
- aperçu en direct et arrondi intelligent au format français ;
- mémoire, historique persistant et réutilisation des calculs ;
- thèmes sombre et clair ;
- PWA installable et fonctionnement hors ligne après la première visite.
